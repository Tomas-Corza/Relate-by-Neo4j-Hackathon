# Local React prototype
Development only. The executive overview is functional; other navigation entries are explicitly disabled. Uses a read-only model-enumerated API and the existing synthetic graph. No AI endpoint or public deployment in this phase. Existing Streamlit entry point unchanged. Node.js 22 recommended. Run `python -m pip install -r requirements-preview.txt`, then `python -m uvicorn preview_api:app --host 127.0.0.1 --port 8000`. In another terminal run `cd webapp && npm install && npm run dev`. Open http://127.0.0.1:5173. Before production: complete other views, adapt and test security/quota controls, lock and audit dependencies, perform browser and integration tests.
