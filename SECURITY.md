# Security policy

OpenClaw Nexus is a public, synthetic-data demonstration, not a production financial system.

Report suspected vulnerabilities privately to the repository owner through GitHub private vulnerability reporting if enabled, or via the contact information at https://tomascorza.me. Do not post credentials, exploit details or personal data in public issues. Do not test against the public demo with disruptive traffic.

The AI analyst has no write-capable tools, shell access, live customer records or advertising account integrations. Never enter confidential or personal data into the demo. Public AI requests are limited; quota enforcement is not a guaranteed monetary cap.

Administrators should use a dedicated restricted OpenAI project key, enable push protection and branch rules, review dependency audit findings, and configure billing alerts. Rotate credentials immediately if exposure is suspected.
